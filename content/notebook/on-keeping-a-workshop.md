## The argument

A workshop is a place where work happens, not where it is displayed. Footnotes,
diagrams, and half-finished thoughts are welcome.

> A notebook is a tool for thinking, not a record of having thought.

## Markdown shows up nicely

Inline `code`, **bold**, *italic*, and links all inherit the bronze accent. A
fenced block:

```python
def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```
